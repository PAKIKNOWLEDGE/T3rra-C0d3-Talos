# 开屏与空任务层预览

独立视觉样张，**不接入引擎，不改 `app/` / `demo/`**。当前产品候选仍冻结。

方案说明见 [空任务层提案](../../docs/proposals/empty-task-layer.md)。

## 怎么看

在仓库根目录打开：

```bash
npx --yes serve preview/empty-landing -p 5199
```

浏览器访问 `http://127.0.0.1:5199/`。

也可直接用浏览器打开 `preview/empty-landing/index.html`（字体走相对路径 `demo/fonts`）。

## 预览里能做什么

1. 开屏：三枚六边形锁位 → 黄线扫描 → TALOS 顶出。点击画面或「跳过」可中断。
2. 空任务层：无活时主表面是邀请，不是空的作业记录。
3. 底栏切换「有记录」，或在输入框发送，看进入作业表面。
4. 「重播开屏」只重放这一层，不刷新整页。

系统若开启减少动态效果，开屏直接跳过。
