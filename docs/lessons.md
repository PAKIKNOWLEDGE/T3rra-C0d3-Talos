# 可迁移经验：记住问题，不继承旧引擎假设

【文档】来源为 Rhodes 的 `docs/status.md` §7–8、`docs/rules.md`、`docs/design.md` 与用户逐轮反馈；本轮读取时 Rhodes HEAD 为 `5a12cacac8229908fd7f7ace641a67bc1b8ad178`。这是经验提炼，不是 MiniMax 已验证契约。需要考古时只读 `C:\DEV\develop\t3rra-C0d3`，日常接手不必通读旧仓。

## 状态与接口

| 旧项目实际问题 | 新项目应保留的做法 |
| --- | --- |
| 历史 load 成功却缺响应 sessionId，输入永久锁定 | pending 保存请求方法、目标会话和代次；不要假设响应重复请求字段。按已核实语义完成加载；成功、失败、超时都有可恢复状态 |
| 快速切会话后旧回放覆盖新选择 | 请求与事件按 session / 当前选择代次隔离；旧结果不得切回旧会话，但后台事实也不能简单混进当前视图 |
| 审批策略刚改好，又被旧读取回退 | 配置读写携带 revision、cwd 和进程代次；只应用仍有效的结果 |
| 刷新丢失回合结局，重复显示用户 prompt | 连接、引擎、回合、视图四种生命周期分开；稳定请求身份、有限补发缓存、去重、明确结局；缓存不完整时明说 |
| 执行中可排队输入，使单一 busy 推断出错 | 先核对新引擎的队列/steering 语义，不能从输入框可用推断引擎空闲，也不能让旧回合结束解锁新回合 |
| 旧事件误结束当前运行 | 结局关联真实回合，不以“最新收到一个结束事件”覆盖全局状态 |
| 整对象替换丢失 binary，按钮成死键 | facts 合并更新；动作前置失败给可见错误和恢复提示，不静默 return |
| 历史会话真实 cwd 与 UI sandbox 不一致 | 历史的目录身份应贯穿选择、宿主和继续执行；从引擎证据确定目录，不从应用当前目录猜测 |
| HTTP 成功、取消发出、审批卡消失被当业务成功 | 请求受理、业务完成、效果确认分别记录；取消要真实结局，删除要权威确认，批准写入要实际文件效果 |

## 分层与证据

沿用单向事实流：引擎报文 → 适配事件 → 合并状态 → 派生视图 → UI。运行时状态与本地时钟也要明确来源。UI 不认识上游方法名或 HTTP 路径；Rust / 开发桥搬运字节和管理系统 I/O，不复制一套业务状态机。

请求、响应、notification、反向请求分别处理。不能把 permission 回复成功等同于文件 I/O 已实现；初始化声明的宿主能力必须真接线，未实现就不声明。先查源码和协商能力，再设计仓库内可重跑的 `spike/` 探针，输出脱敏证据到 `traces/`；TEMP 一次性脚本不能作为入库证据的唯一来源。日志不用含密钥或私人会话。

字段不存在就保留缺失，不为 demo 补造 usage、计划、文件清单、模式或进度。新字段先登记映射和有损项，再改版本化的内部契约、状态、视图和测试。通用契约不能强塞只有 opencode 才能产生的字段。

若实现节奏诊断，静默只是观测，不是失败证明；不要把任意毫秒阈值变成权威状态。样本不足明确“未建立”。没有产品需要就先不做这项，别照搬旧阈值作为 MiniMax 事实。

## 视觉与交互

- 换族只换颜色会失败；构图、组件、文案和动效都属于设计。当前 Talos 已有通过的范本，先忠实迁移；模型想“提升质感”不能成为重新设计的理由。
- 信息不能挤满每块空白；中间阅读区面积与留白优先，旁栏只放辅助信息。长路径和标题不得挤走按钮。
- 工单默认低噪摘要，但过程必须可查看；详情用浮窗承接长参数、输出与错误，避免撑坏主记录区。
- 资源条多次错位最终是 `.orders` 名字冲突导致 grid 覆盖。先查组件样式归属，用明确作用域，别不断叠基线、padding 修补。
- 全局动效要覆盖进场、会话切换、浮窗、控件反馈；流式文本不要每帧重播进场、抢焦点或强迫用户跳回底部。保留 reduced-motion。
- “浏览目录”应选中、确定、自动导入。只打开资源管理器让人复制路径不是闭合交互；确定、取消、失败、超时都要可操作。
- 文案用功能名词和事实；不要“你不开口就不建会话”这类拟人俏皮话。空态说明下一动作，缺失说未报告。
- **确认与危险操作**：禁止 `window.confirm` / `alert` / 浏览器「通知」权限承载产品决策（Firefox 等会误拦）。删除、覆盖、不可逆动作一律用壳内 `#detailDialog`（或同视觉体系的 modal），主/次按钮贴 Endfield 色；`ui-manifest` 登记。临时 `confirm` 仅作 WIP，验收前必须换掉。

## 桌面与系统

先保留浏览器开发入口和统一 transport，再迁移 Tauri 2 宿主；浏览器通过不代表桌面通过，窗口出现不代表引擎通了，debug exe 不代表可分发安装包。

stdout 按真实协议分帧，验证 LF、UTF-8 跨块、尾帧、stderr 分离；以进程代次隔离重启后的旧输出。Rhodes 曾因 Rust `Child::wait()` 提前关闭 stdin，造成窗口正常但无法通信：读清 API 生命周期，再设计监控，不仅测“能 spawn”。连接断开不等于子进程退出，更不等于 prompt 完成。

验证 Windows 启动器、中文/空格路径、原生目录对话框、无引擎恢复入口、进程树归属和退出清理。应用目录不是用户项目 cwd；默认 sandbox 不得覆盖历史项目身份。不要照搬旧配置文件名、账号存储或引擎定位优先级。

## 明确不迁移的东西

opencode 的 `close → HTTP DELETE → list` 只能解释旧项目经验，不能当 MiniMax 删除流程；其 cancel 形态、load 响应、fork/resume、配置键、权限持久化、HTTP 端口、版本范围和环境变量均需重新取证。ARK 的蓝色主操作、3NDM1N15T4T0R 的 ARK 令牌和“END 冻结”只属于 Rhodes；Talos 正本见 [design](design.md)。
