# Tauri 2 外壳（plan 带 6）

Talos Desktop 当前以 **Vite 产品壳 + 观察服务**（`npm run dev:product`）开发。Tauri 2 是 **发行形态**（[plan 带 6](plan.md)）。门禁是带 0 目视过，不跟 fork / 插件 / 附件绑死。

## 进入 Tauri 前的产品门禁（非探针）

1. 工作区可在产品内切换（或 Tauri 原生选文件夹）。
2. 对话、停止、审批闭环可用。
3. 模式/模型可写或明确引导至 CLI。
4. 依赖 `talos` 的前置与失败态在 UI 可读。

## Tauri 轮交付物

- WebView 加载与现 `app/` 等价的资产与字体策略。
- 可选：安装包内 **sidecar** 捆绑同一份 `talos` CLI（仍非第二套 agent）。
- 系统文件夹选择器替代浏览器手填路径。

## 明确不在 Tauri 首轮

- 改 demo 构图。
- 把引擎模块打进二进制绕过 `talos studio`。
- 用空壳安装包掩盖未接线的控制台控件。
