# 提案：空任务层 + 开屏（用户已确认，待产品接入）

状态：已接入产品并随0.1.2由用户验收。本页保留方案理由与预览审查，不派任务；实施事实见status，现行任务见plan。

触发：用户要求桌面也有「无任务时的独立表面」，以及一套开屏；视觉仍用已确认 Endfield 语言。Codex 截图只说明「空任务是一层，不是空记录」；颜色、构图、字体不以 Codex 为准。

可看样张：[preview/empty-landing](../../preview/empty-landing/README.md)。

## 要解决什么

| 现状 | 问题 |
| --- | --- |
| 无 `sessionId` 时，主列仍是作业记录壳，里面塞一块 `.empty` | 空任务被当成「没有内容的记录」，不是一种产品状态 |
| 有会话但尚无消息时，只显示「当前会话尚无消息」 | 第一条指令没有独立邀请面 |
| 进场是顶栏/侧栏/输入区分别 rise | 没有开屏，也没有「从关机到工作台」的一次性编排 |

抽象层含义：空任务与有记录是主表面的两种模式。左右栏、顶栏、输入区还在；中间从「邀请开始」切到「阅读记录」，不把邀请写进 timeline。

## 视觉约束（正本不变）

沿用 [design](../design.md)：浅灰顶栏、石墨阅读区、黄色主操作、六边形徽标、Harmony / Bahnschrift、现有密度与圆角。不换暗紫、不换居中聊天气泡、不加第二套 token。

本轮预览参考用户本地图：浅灰点阵底、黄色斜切面、深色六边形与 TALOS 字标、小尺寸识别条；保留原锁位与揭幕节奏。减少动态时跳过开屏。原暗底版仍留 Git，用户本次已选定 8e52c77 版本。

## 预览已演示的行为

1. **开屏（约 2.2s）**：浅灰点阵底与黄色切面入场 → 三枚深色六边形依次锁位 → 细线扫过 → 字标顶出、深色短杠拉出 → 帷幕揭开，工作台已在空任务层。可跳过、可重播。
2. **空任务层**：无活。主列垂直居中邀请（黄杠标签 + 大标题 + 一句说明）；徽标低幅度待机，不是思考云。输入区仍是现有 composer。
3. **有记录层**：选活或发送后，主列回到记录头 + 消息流；侧栏出现当前活。

## 方案确认后拟接入文件

| 路径 | 拟做 | 不做什么 |
| --- | --- | --- |
| `app/index.html` | 增加开屏节点；主列增加空任务表面，与 `#stream` 并列 | 不重排三栏宽度 |
| `app/product-motion.css` | 开屏时间轴、空层待机、揭幕与现有 rise 衔接 | 不改已确认控件反馈曲线以外的全局动画 |
| `app/product.css` | 空任务表面布局（可从预览收敛） | 不改色板、字号、顶栏高度 |
| `app/talos.js` | 按已审核优先级派生空态/记录/加载/失败；开屏在壳载入时最多一次，与连接并行 | 不改 Studio/会话状态机；空层不是新引擎状态 |
| `app/ui-manifest.json` | 登记开屏跳过、空层容器 | 登记不等于已验收 |
| `demo/*` | 默认不动。若要把空层收进视觉正本，另开视觉任务并走用户验收 | 不借本预览改 demo |
| `src/view` 及必要历史显示标记 | 允许实际产品共用的纯显示 helper；缺历史加载完成信号时按 V1 合同最小补齐 | 不改引擎协议、历史投影或状态所有权 |

产品条件（本次审核修订；具体任务切换见 plan/status）：

- 开屏生命周期属于壳载入，连接立即并行开始；不能等到连接成功才开始/结束动画。每窗口载入最多一次，超时兜底与 reduced-motion 均揭开真实当前页面，不重置会话，不用动画伪造加载进度。
- 空任务层根据已有快照派生；只有无可显示内容、无 pending 审批/问卷、无历史加载/失败、无运行/停止且无当前错误时才显示邀请。事件页和可恢复错误优先。明确区分无会话和已创建的空会话。
- 新建/打开/发送由真实动作与 snapshot 决定显示；新建成功但尚无内容可以留在邀请面；提交失败保留输入/错误入口，不把预览的模拟 setLayer 当成产品状态机。
- 开屏不阻塞连接、不捕获后台用户操作；必要的短时遮罩有明确跳过焦点。结束后删除/隐藏装饰、解除输入限制；只在用户尚未选焦点且可输入时恢复合理焦点，不无条件延时 focus。
- 流式、切会话和重连不重播；预览重播/空态切换/模拟记录/固定用量不进入产品。

## Codex 源码审核（2026-10-12）

审核的是预览源码与拟接入方案，**不是画面通过**。尝试用可见浏览器打开 file 页面被协议策略阻止，本次没有观察动画；JS 语法检查退出 0。构图与节奏由用户指示。

| 源码观察 | 接入前处理 |
| --- | --- |
| endSplash 固定 setLayer(empty) | 只移除遮罩，底层由实时 snapshot 正常投影；避免动画结束遮住已加载会话 |
| 只按空 timeline 派生空态 | 加入上述错误/加载/运行/交互优先级，不改变 FactStore |
| 开屏 role=dialog，但背景可键盘聚焦，结束延时 focus | 明确跳过与焦点管理；不让 Enter/空格误触底层，不抢既有焦点 |
| splash-word 固定高 54px 且 overflow hidden，文字与黄杠的布局合计超过容器 | 可见预览确认黄杠是否裁切，再仅调整该容器；不顺手改全局字号 |
| landing.css 定义整套色板/字体/三栏/控件 | 只提取专属样式，复用产品 token 与现有结构，不复制整页 |
| 预览服务根目录为 empty-landing，字体相对路径指向根外 demo/fonts | 预览文档改用仓库根作为服务根；产品用既有字体路径，不新依赖 |

约 2.2 秒是预览演示时长，不是性能目标；用户决定保留或缩短。首次体验要能立即跳过，重复使用窗口不因快照更新增加等待。
