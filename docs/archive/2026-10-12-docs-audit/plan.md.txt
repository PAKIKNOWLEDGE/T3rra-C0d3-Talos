# Talos Desktop 路线与当前任务

## 产品路线

以用户已满意的 CLI 与视觉交付 Windows 桌面终端。Tauri 2 管系统 I/O 和生命周期，桌面通过 `talos studio` 连接引擎；不退回 ACP、不换 Electron、不复制 CLI 业务。

| 阶段 | 结果 / 后续边界 |
| --- | --- |
| R1 / R2 | 记录接驳与基本操作，保留已有能力；验收事实见 status |
| V1–V3 | 开屏/空态、文案与视觉已收口，不重复设计 |
| R3 | Windows 0.1.2 安装候选已用户通过；遗留问题独立登记 |
| 发布 | 文档、截图、版本、产物与许可边界一致后交付；授权和执行事实只记 status |
| R4 | 从已发生问题或明确需求中选择一个有界结果，不自动执行整张能力表 |

旧 R3/V 序列合同保存于 [2026-10-12 归档](archive/2026-10-12-release/README.md)，不继续派发已完成任务。
