# 开屏与空态设计约束

该方案已进入产品；本页只保留设计理由和维护约束，不再列拟实施文件或预览排错队列。视觉正本见 [design](../design.md)，实施/验收结果见 [status](../status.md)。旧提案与预览审查原文见 [快照](../archive/2026-10-12-docs-audit/proposals-empty-task-layer.md.txt)。

## 设计理由

开屏用于一次性的产品识别；空态是在可开始任务时给出下一动作，不是写入会话记录的伪消息。顶栏、两侧与输入区仍保留，主列根据实际状态显示邀请、记录、加载或可恢复错误。

[预览](../../preview/empty-landing/README.md) 仅演示构图和节奏；重播、模拟记录和固定用量不能进入生产路径。

## 必须保留的行为

- 连接与壳载入并行，不等待开屏完成。每窗口载入最多播放一次；跳过、reduced-motion、结束与异常兜底均揭开真实页面。
- 空态根据实际snapshot派生。历史加载/失败、错误、工具记录、运行/停止、审批、问卷和事件页优先，不能以timeline为空遮住这些内容。
- 无会话与已创建的空会话分开表示。首次无工作区提供实际目录入口，不能显示连接成功或伪造会话。
- 新建、打开和发送的结果由真实动作与快照决定；提交失败保留输入和错误入口。空层不是新引擎状态，也不能写进timeline。
- 遮罩有可键盘操作的跳过入口。结束后释放输入限制，仅在适当条件恢复焦点；快照、重连和切会话不重播、不抢焦点。
- 专属样式复用现有token与composer，不搬预览整套三栏、色板或模拟状态。
