# 桌面产品边界与对标

本页解释产品方向，不分派任务，也不维护完成度。当前路线见 [plan](plan.md)。

Talos Desktop 是本机 Talos CLI 的图形工作台。用户满意的 CLI 与视觉是已有资产；用 Studio 接入同一引擎，避免桌面重新实现模型调度、会话持久化与权限。

## 工作台应提供的结果

| 区域 | 用户结果 |
| --- | --- |
| 左侧 | 识别工作区与会话，打开和继续已有工作，明确哪些正在运行 |
| 中间 | 忠实阅读任务记录、思考、工具过程和错误，能够停止 |
| 右侧 | 理解当前任务的相关信息与待处理事项，不用原始事件噪音填空 |
| 输入区 | 发送内容，使用已接通的命令与配置；后续按需要完善投料 |
| 桌面壳 | 真窗口、系统目录选择、明确的引擎连接与退出行为 |

Codex 等成熟工作台仅作用户体验参考，不从对标名称推导云后台或全部功能承诺。具体接口按 Talos Studio 源码，视觉按本仓已确认 demo。

## 保留与后续取舍

队列、分叉、回退、编辑、检视等已有源码先保留，不因未经本轮验收就删除；具体收口由任务决定。不得用缩小任务范围作为删除已有入口的理由。

登录、provider、CLI 更新与插件管理继续沿用 CLI 的既有入口，除非另有明确产品决定。云同步、手机派活、并行多通道、内嵌终端、完整 Git 审查台不属于当前桌面交付合同；没有相关任务不建立空入口。

缩小单轮范围不代表删减最终产品；每轮必须交回一份可以继续使用或明确回退的候选。
