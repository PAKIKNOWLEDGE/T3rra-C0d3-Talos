# Talos Desktop 路线与当前任务

## 产品路线

保留已确认的CLI与视觉，通过Studio接驳Windows桌面。模块边界见 [桌面宿主](tauri-shell.md)，实际版本、验收与发布状态只见 [status](status.md)。

| 范围 | 维护目标 |
| --- | --- |
| 记录与基本操作 | 忠实展示消息/历史与工具，打开/继续/停止/审批有明确结果 |
| 视觉与空态 | 保留确认的开屏、文案、布局与控件；只修明确回归 |
| 桌面交付 | 安装资源、工作区、CLI定位、服务与退出属于宿主责任 |
| 后续完善 | 从用户反馈或明确需求选择一个结果，不把Studio方法表自动变成待办 |

旧V/R3合同见 [归档](archive/2026-10-12-release/README.md)，不继续派发。
