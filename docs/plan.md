# Talos 当前计划

本页只保留产品边界、本轮方案及下一入口。当前事实与验收见[status](status.md)，执行规则见[workflow](workflow.md)。旧完成步骤见[归档](archive/2026-10-06/plan-before-doc-refresh.md)，只用于追溯，不再作为待办。

## 目标和范围

维护自己的Talos CLI，保持平级provider、独立数据目录、已验收TUI及ACP边界。GUI恢复后沿既有范本接入，再做Tauri2外壳；不使用Electron。原始版权、NOTICE、第三方许可、权限和沙箱边界保留。

不从零证明继承引擎的全部能力。任务来自具体故障、实际改动影响或确认的交付缺项；未验证本身不是无限检查的理由。当前CLI已发行，GUI工作暂停。

## 本轮文档整理

接收NixOS远端文档，记录真实使用已确认正常和两项自动检查未通过。校正过强归因、错误PASS标记及无效链接；不调整测试或重跑验证。当前两仓库文档改为事实、操作和规则的直接叙述，去除人物旁白；保留真实来源、版权、技术标识和历史证据。

本轮仅文档、文档清单和对应Git收口。新体验问题只留范围，不查代码、不实施、不发npm。

## 后续体验问题

后续只讨论两个已经发生的可见问题：

1. 等待期间出现无明确可见原因的重复短回复。目标是在没有实际变化时不打断对话，结果、失败或需要操作时再报告。
2. 内部agent标签被当成人格或责任方，混入回复和项目文档。目标是输出遵循产品和任务语境；必要技术标识只作为数据呈现。

详细症状保存在CLI docs/superpowers/plans/2026-10-03-nixos-followup.md，验证结果保存在CLI docs/verification.md。下一轮开始后再确定来源层及最小修复，不能先认定为上游故障或提前选择提示词方案。本轮不调查；完成文档接收也不自动启动实现。

## 首次 npm 预览版与搜索后置

CLI预览版不包含默认联网搜索、便捷搜索配置或GUI/Tauri。自配MCP搜索尚无实测，不能作为默认搜索宣传。增加这些能力需另行确定任务范围。

## npm 发行与版本提醒

包名为@pakiknowledge/tal0s-code，命令为talos；版本独立于上游。更新只显示准确的手动npm命令，不内联安装。发布必须有明确授权和同提交候选证据，已发行标签不移动。

本轮不查询或再次发布npm。具体版本状态见status，不从旧的注册表同步记录猜测现在的latest。

## Git主线与上游边界

CLI main是唯一长期产品线。工作从main建短期分支，交付后收回主线并清理；恢复依靠提交与标签。upstream为只读公开来源，按[讨论先行流程](workflow.md#选择性接收上游-pr)选择，不自动合整条上游主线。

内部源码导出契约与选择性公开PR移植分开，不能因接收一个PR随意推进sourceRevision。原#199/#388/#410文字修复已收口，其余候选只在status保留一份复看列表。
