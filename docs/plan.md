# Talos Desktop 产品路线与当前任务

## 产品目标

在用户已经满意的 Talos CLI 上，以已确认的 Endfield 视觉交付 Windows 桌面工作台。保留 CLI/TUI 的引擎能力与语义，通过 talos studio 接驳。界面布局以 [design](design.md) 为正本，现状与授权只读 [status](status.md)。

## 路线与停止点

| 阶段 | 交付结果 | 进入下一项的条件 |
| --- | --- | --- |
| R1 对话记录忠实接驳 | 流式正文、完整消息、历史工具顺序可靠，内部 JSON 不污染记录 | 本任务技术复核与用户验收通过 |
| R2 基本操作可靠且可证明 | 打开/继续/停止/审批可确认；辅助检视不挡会话；验证覆盖实际生产路径 | 对应候选通过；仅修明确缺陷或交付欠账 |
| R3 Tauri 桌面候选 | 真窗口、系统选目录、明确的引擎定位、启动/退出管理；沿用同一 Studio 和视觉 | [桌面交付边界](tauri-shell.md) 的验收通过 |
| R4 按使用价值完善 | 按实际需求收口队列、分叉、回退、检视等已有接线和后续能力 | 每次独立结果，不把 Studio 方法表当自动待办 |

路线表示依赖，不表示一次性编码授权。R2 具体任务在 R1 结果基础上展开，不重跑上游能力证明。已有高级能力保留，出现明确故障才处理；R3 不等待高级功能全部完善。最终安装与分发不能用开发窗口替代。

### 实施范围与方案

采用行为保留的局部提取。优先复用 `src/view/message-markdown.ts` 作为唯一纯渲染模块，由 `app/talos.js` 显式导入；现有 Vite 允许读取仓库根目录，无需新框架。导出实际需要的块渲染入口，让 assistant 正文、用户正文和思考在各自既有消费路径下使用共享代码。模块中的能力须由生产消费或明确兼容入口解释，不能保留仅供单测的第二份实现。

执行前比较两份实现的真实差异，以当前 `app/talos.js` 行为为准；保留字符串转换、空白处理、HTML 转义、用户换行、思考格式及代码块分段。`formatMessageText` 等记录语义继续由原层负责，不借提取改变消息或思考身份。相关文件限于上述模块、实际消费者、已有 Markdown 测试及必要的少量入口检查；普通导出和导入调整由 Cursor 决定并记录。

不修改 CSS、demo、表格功能范围、Talos-CLI、Studio 协议、FactStore、操作状态机、依赖或全库类型配置；不顺带统一 slash 等其他重复代码。模块加载确有障碍时先给最小证据和方案，不另造平行渲染器。

### 完成条件与验证

1. **改前基线。** 先运行现有 Markdown 定向测试；对当前生产函数记录基本表格、普通正文/强调、列表、代码块、HTML 字符、用户换行与思考块的输出。基线来自真实生产函数，不能只取另一份实现的结果。
2. **唯一实现。** 浏览器实际入口导入同一纯模块；测试调用该模块。生产文件中不再保留 Markdown 解析与表格拼接的另一份函数。不得复制实现到 fixture 或测试 helper。
3. **行为不变。** 改后对同组输入比对 HTML 输出；特别保留 K2 表格、列表/代码混排和转义。已有断言继续成立，不扩大 Markdown 支持范围，不通过改期望掩盖输出变化。
4. **入口可加载。** 有限的 Vite 转换或构建检查证明 `app/index.html` → `app/talos.js` → 共享模块的真实导入链可解析。可以使用不监听端口的 Vite API，结束后关闭自有实例；不能用伪 DOM 拼装另一份产品，也不能使用禁止浏览器工具。
5. **候选交付。** 先完成受影响检查，再按 README 跑一次适用的 `check:all`；记录命令、退出码、生产基线比对和入口解析证据，保存候选。无真实模型请求，不启动长期验收服务，不杀用户服务。

技术收口以共享实现、原行为一致与入口可解析为准。可见浏览器未观察就注明未验；本轮没有新视觉设计，不要求用户重复 K1/K2 验收。用户正常使用若发现直接回归，按同一任务退回并计数。

### 交付之后

本轮只收口渲染同源这一项。下一步准备 R2-B 打开/继续/停止/审批的实际操作合同，先复用已有证据，只修具体故障或必要交付欠账；R1 尚未记录的整体操作可随对应路径补齐，不重新全库排查。R2-B 通过后进入 R3 Tauri 与 Windows 交付，R4 按需完善不挡 R3。后续任务尚未授权执行。

R1 的已执行合同可从 Git `5472112:docs/plan.md` 追溯，K1/K2 验收与尚未确认的事实保留在 status；旧合同不再作为另一条执行队列。
