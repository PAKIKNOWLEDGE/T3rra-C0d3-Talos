# Tauri 桌面宿主边界

本页规定宿主责任，不派发已经完成的R3，也不维护候选与发布状态。任务见 [plan](plan.md)，交付/验收见 [status](status.md)，操作命令见README。

## 运行结构

Tauri 2加载本地打包前端，管理原生目录选择与自有子进程。随包Node运行编译后的桌面服务，服务通过`talos studio`连接已安装CLI；复用TalosService/FactStore与同一消息投影。

宿主不复制模型、工具执行、权限与持久化，不创建第二套回合状态机，不直接导入CLI内部模块，不自动升级CLI。队列、分叉等已有能力保持接线，不因窗口阶段而删掉。

## 维护条件

1. 安装后启动不依赖源码checkout、Vite或代理遗留服务；资源与随包运行时共同部署。
2. 工作区由用户选择，有效目录可记忆；取消不改变会话，失效目录有明确恢复入口。
3. CLI定位/启动失败展示原因，不假在线；首次无工作区不能偷偷使用安装或源码目录。
4. 自有随机loopback端点与认证凭据按进程管理；最小原生权限，不给页面任意shell执行能力。
5. 退出清理自有服务/引擎，不按端口或进程名结束用户服务。

检查对应实际安装形态；NSIS与MSI分别取证，不能互相代替。画面由用户手动验收，资源/连接检查不冒称渲染通过。资产边界见 [design](design.md#资产与分发)。
